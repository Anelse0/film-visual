# 验收报告｜1.1.0

验证日期：2026-09-23。发布源码、独立 ZIP 与实际被测安装副本一致。本报告区分新增方法、观察到的行为和未验证的生成质量。

## 提升了什么，如何体现

| 本轮变化 | 可观察体现 | 证据与界限 |
| --- | --- | --- |
| 新增可追溯的审美依据与迁移边界 | 阅览室任务能指明借用了哪个案例的配色/窗光方法，并明确排除红土、沙漠、黑白等不适用元素 | [旧版 A04](evidence/1.1.0/baseline-A04.md)如实说明包内没有案例；[新版 A04](evidence/1.1.0/candidate-A04.md)使用随包来源。这是本轮最明确的新增行为。 |
| 构图与画幅决定增加明确取舍和检查方法 | 修鞋铺选择 4:3，并说明少展示两侧环境的代价；检查两张脸、双手与台面的关系 | [旧版 A01](evidence/1.1.0/baseline-A01.md)、[新版 A01](evidence/1.1.0/candidate-A01.md)。旧版已能给出合理设计；新版此样本更明确取舍，不能据一次输出推断整体审美胜率。 |

| 审阅明确绑定用户目标和局部修改 | 实际看图后识别右上标牌竞争、人物与椅面混合，建议局部调整灰阶，并保留粗颗粒、空墙和低位人物 | [A05](evidence/1.1.0/candidate-A05.md)。有真实视觉工具调用；没有修后图，不声称修复有效或成图更美。 |
| 色彩/光线方法与审美反例进入成稿 | 浓彩舞厅仍保留多中心；红光肖像保留汗光；黑白修表室通过灰阶和材料区分主次 | [A06](evidence/1.1.0/candidate-A06.md)、[A07](evidence/1.1.0/candidate-A07.md)、[A12](evidence/1.1.0/candidate-A12.md)。验证目标遵守与文本设计，不等于实际输出图像达到效果。 |

## 确定性与安装验证

- 源码和发布 ZIP 解压副本各运行原有标准库 unittest：**10/10 通过**。覆盖自包含、内部链接、模板状态、编码/换行、授权字节边界、错误区间、安装与输出不覆盖等原有约束。
- skill-creator 格式验证器返回 **Skill is valid!**。首次缺少 PyYAML，在本工作区临时安装 PyYAML 6.0.3 后完成验证；不是运行依赖，未安装到全局。
- 发布 ZIP 共 **15 个文件**，CRC、SHA-256、逐文件内容与源码一致。用 ZIP 解压副本的安装器装到全新项目，拒绝依赖开发资料；最终安装内容再次与发布源码逐文件比较相同。
- A08 对 Agent 实际保存的文件作独立字节核对：LOOK 正文外所有字节相同，CRLF、空行、中文台词、全角标点和行尾空格均保留，original.txt 与预先给定输入相同。新段落包括自然日光、木与金属、人物受光关系，没有增加镜头或动作。原始/修订全文、字节区间和 SHA 在 [机器可读证据](evidence/1.1.0/behavior.json) 的 byte_check 中。
- 本地草图生成器重建的 PNG 与被测输入逐字节一致。生成器在 tools/make_review_fixture.py，Pillow 仅用于开发测试，不在 Skill 安装包中。

复核发布产物：`python3 tools/build_release.py --check`。源码测试命令见仓库 README。

## 尚未验证

**真实图像生成、参考编辑后的画质、身份保持、视频生成及动态连续性全部待测。** 未调用收费图像/视频服务，也未上传媒体。

本轮只有一张本地程序绘制的构图草图，验证“能看见问题并遵守目标”；不代表复杂摄影作品、不同文化风格和所有审美任务均已验证。没有多次抽样或用户盲评，因此不报审美提升百分比，不声称新版每个任务都优于旧版。

规则和案例会影响模型当次选择，未训练或微调底层模型。宿主能力仍然影响质量。方法、文本、图像和视频是不同验证层；新增依据和更明确的取舍不能单独证明成图更美。
