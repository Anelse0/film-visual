# 验收摘要｜1.0.0

验证日期：2026-09-22。产品依据独立开发交接方案 v1.1 实现，发布产品版本为 1.0.0。本文件概括已执行结果，不把规则文字或用例清单当成行为通过证据。

## 确定性测试

源码和安装 ZIP 解压副本分别运行标准库 unittest：每次 **10/10 通过**。覆盖：

- 入口名称、内部引用与自包含检查；项目专属默认泄漏辅助检查；模板默认未批准状态。
- UTF-8 BOM、混合换行、UTF-16、多授权区间的原字节保留。
- 哈希过期、原字节不匹配、空区间、越界、重叠等错误拒绝。
- 编辑输出不覆盖原件或已有文件；符号链接输出拒绝。
- 项目安装不覆盖用户现有文件；链接安装父目录拒绝。

补充的 skill-creator 格式验证器返回 `Skill is valid!`。验证器的 PyYAML 只安装在开发工作区，未成为 Skill 或自身测试的运行依赖。

安装包 CRC、逐文件 SHA-256、最终隔离安装副本与发布源码一致性检查通过。四份 Agent 实际生成的修订文件（LOOK、基调、跨场视觉、自然段）均通过授权区间之外的逐字节比较，其中一份包含 CRLF、中文台词、全角标点与行尾双空格。聊天排版不作为编码保真证据。

## 实际 Agent 验证

宿主为 macOS 上的 Codex CLI `0.155.0-alpha.9.2`；有完整上下文记录的会话使用 CLI 默认模型 `gpt-5.6-sol`，未手动指定模型。测试使用全新会话与独立运行目录，未继承开发对话或开发参考正文。最终核心、看图、歧义及多轮会话的可用 Skill 目录记录仅含 `film-visual`。

外层 OS 沙箱拒绝读取两个旧影视 Skill、开发参考和开发源码，允许读取复制安装的 Skill；最终副本测试还拒绝读取第一轮测试目录。上述访问边界通过文件打开权限探针实测。所有写入限制在已授权开发工作区。未更改全局安装。

共保留 27 个完成 turn 的本地证据，含首次失败及重测；这不等于 27 次全部通过。原始输入、输出与可公开的工具调用证据已随本地交付物提供，本仓库不复制包含机器路径的运行日志或图片。

| 场景 | 实际结果 |
| --- | --- |
| 单条 club MJ prompt | 直接输出一条带舞池、DJ、活动空间及 16:9 的成稿 |
| bar→club 纠正 | 同一会话连续两轮，第二轮从吧台核心改为舞池和 DJ 核心 |
| 黑白粗颗粒动画方案 | 给出黑白明度、造型、纹理与空间设计，无外来项目审美 |
| 仅本场中性化 | 只调整当前场次，保留全剧及其他地点暖色规则 |
| 保布局、减反射、重照明 | 本地看图后区分结构保留与光色改变 |
| 缺人物原图 | 请求实际目标图，不把环境图冒充人物或已绑定素材 |
| 中性人物图 | 不带入剧情夜色或污迹，不虚构已完成锁脸 |
| 单面房间反打 | 沿用已知关系，未见墙面明确标为新增设计 |
| 无分镜视频基调 | 直接交付；最终版对未知灯位明确标注布光提案 |
| 仅基调、完整修订稿 | 返回全文，实际文件中非授权字节保持不变 |
| 段外照明冲突 | 保留未授权绑定，明确指出全文仍有冲突 |
| 跨空间及末镜手电 | 分别描述各空间光线，手电仅限原定末镜 |
| LOOK 与自然段 | 正确定位范围，保留文件段外内容 |
| 多 LOOK 歧义（补充用例） | 首次失败，规则修复后改为先确认 A、B 或两处 |
| 仅图片审阅 | 实际看本地合成图给判断，无项目写入或生成 |
| 转头技术测试 | 自行交付简单测试，无新增正式剧情对白 |
| 指定文件保存 | 只写指定成果，保留草稿、未采用、未生成状态 |
| 脱离开发包 | 最终独立副本重跑单条 MJ 与无分镜基调成功 |
| 跨项目隔离 | 冷灰工业与新会话暖色绘本各使用自身要求 |

最后两项规则调整为：未知灯位明确标为提案；多个 LOOK 的含糊指代不能自动视为全选。相关任务已在最终发布副本重测；其他场景是修订前候选版的真实记录，未声称所有场景都在最后改动后再次运行。

初期运行目录和临时文件受 OS 沙箱限制，配置工作区内运行/临时目录后完成测试。部分模型目录刷新及统计请求超时，但对应 Agent 任务有实际完成事件，未将这些环境错误计为通过项。

## 尚未验证

**真实图像生成、参考编辑画质、人物身份保持、真实视频及动态连续性全部待测。** 本轮没有媒体上传或收费图像/视频生成调用。本地程序绘制的匿名测试图只用于验证看图与编辑指令行为，不是模型出图效果证据。

其他宿主的自动发现和实际生成平台界面、账号参数及素材绑定方式未实测。模型官方能力核对记录与链接在各适配文档中；它们不等于实际账号和生成效果通过。

Skill 仍依赖宿主理解用户授权。字节工具保证已选区间外不变，不能自动证明区间选择正确；一次歧义修复的通过不代表解决所有自然语言歧义。
