# 1.1.0：审美方法与依据设计

目标：让 film-visual 对风格、构图、画幅、色彩、光线作出可解释、可编入 prompt、可用实际画面复查的选择。保持单 Skill、自包含和短请求直接交付；本次不增加生成接口、向量数据库、打分器或其他影视 Skill 依赖。

## 调研与材料选择

2026-09-23 阅读并核对六部作品的一手访谈/制作团队材料，以及 Disney Animation 官方灯光流程。可追溯短摘要、岗位、原始链接、文章定位和适用边界统一保存在 [style-cases.md](../film-visual/references/style-cases.md)，不另复制资料全文。

选择覆盖不同问题的材料：环境大色块、简洁空间光影、偏置留白、画幅与黑白材料分离、非写实边缘、皮肤光泽、跨场次变化。只以名气、导演标签或截图色板分类，难以解释何时该用，因此没有建立人名风格预设库。

材料层级明确分开：主创说明、记者分析、本 Skill 方法推导；没有把未观看的完整影片声称为逐帧研究。影视图片留在原来源，仓库和安装包不包含第三方媒体。依据材料可追溯，但不要求运行时联网。

## 实现结构

| 文件 | 决策职责 |
| --- | --- |
| `references/design-methods.md` | 风格的形/线/材质、构图注意力、画幅取舍、颜色面积与角色、光线与表面的关系 |
| `references/style-cases.md` | 7 条来源条目；每条区分原作品事实、方法迁移、适用边界 |
| `references/visual-review.md` | 实际看图后按目标判断；观察、原因假设、局部修改、复查对应 |
| `SKILL.md` 与三个原模式模块 | 按问题读取方法，进入实际方案、单条 prompt、编辑与授权 LOOK 修订 |
| 两份原模板 | 可选记录关键选择、取舍、方法来源和可观察验收点 |

工作方式：当前目标与约束 → 选择相关方法 → 写出具体可见关系 → 提供所需成稿 → 有实际图片后再审阅与局部修订。多个方向仅在用户需要时提供；一条 prompt 不附研究报告。

例：宽画面转竖画面时，须确定哪些信息不能丢，再说明裁切、换机位、拉远或扩展区域的代价；已锁定结构的任务不自动搬动家具。此能力属于设计判断，并非自动图像裁切器。

## 保留的边界

用户审美和事实优先。粗颗粒、强彩光、多中心、偏置留白、低对比或皮肤光泽不自动判为问题。案例的角色、场所、年代、色板不得变成通用默认，B/D 项目实例也不进入新默认。

已有 prompt 只改授权区间；新方法不能借机增加镜头、动作或故事。图像/视频生成、上传与收费服务继续不执行。没有改动安装器或字节替换器的功能。

## 验证设计

- 对同一组现实任务保留升级前后原始文本，使用同一宿主默认模型和全新会话。评价具体选择和边界，不用关键词命中或自评分代替效果。
- 从发布 ZIP 安装到隔离项目，只向 Agent 暴露 film-visual；OS 访问探针和实际 Skill 目录记录核实隔离。
- 测试新任务中的方法迁移、风格差异、画幅冲突、群像/浓彩反例、黑白材料、实际看图、局部 LOOK 修订和项目独立性。
- 用本地绘制的匿名构图草图测试实际视觉读取。草图仅是诊断输入，不是生成质量样本；不提交图片媒体。
- 沿用原有 10 项标准库测试检查自包含、安装和字节保真。实际结果与限制见 [VALIDATION.md](VALIDATION.md)。

不把文档更长、案例更多、模型一次给出好答案视为审美提升证明。前后均能做到的部分如实记录为保留能力；只有有证据的变化才计为本轮观察。
