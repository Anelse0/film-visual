# A12 | 1.1.0

## 原始请求

请为黑白动画的小型修表工作室写一条图像 prompt：穿深色衣服的修表人坐在深色木柜前，观众必须先看清手中的小钟；画幅4:3。希望黑白、粗线条、纸感、朴素，不要照片写实。只给中文成稿，不要论述。

## 实际输出（仅路径脱敏）

4:3画幅，黑白手绘动画，一间朴素的小型修表工作室。正面中近景，穿深色布衣的修表人坐在深色木柜前，双手在胸腹之间托住一只小钟，钟面朝向观众，完整露出，手指不遮挡刻度与指针。小钟位于画面中央偏下，大小足以清楚辨认，浅白钟面与深色衣服形成全画面最鲜明的明暗对比，成为第一视觉焦点。画外左上方的工作灯集中照亮小钟和双手，脸部保持柔和中灰，五官简练。衣服以近黑色块表现，木柜以稍浅的深灰和稀疏木纹表现，肩臂轮廓清晰分离；柜门接缝避开小钟与手部。画面下缘仅露出少量工作台、镊子与零件盒，细节克制。粗犷略有抖动的手绘轮廓，平涂黑白灰块面，轻微铅笔排线与纸张纤维质感，安静、质朴；不使用彩色、照片写实、三维渲染、耀眼金属反光或繁密背景。
