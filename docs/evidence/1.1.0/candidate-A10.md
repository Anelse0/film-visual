# A10 | 1.1.0

## 原始请求

给小型停车层写一段视频画面基调，没有图片、没有分镜、灯位没定。目标是明亮、平常、有生活气，不要阴森，不写故事或镜头表。车漆、混凝土和人物服装都要可辨。

## 实际输出（仅路径脱敏）

建议以自然写实的质感呈现小型停车层：整体曝光明亮舒适，中间调充足，保留车位线、地面磨痕和混凝土的细微粗糙感，形成平常、有人使用的生活气息。布光提案以顶部长条灯的中性柔白光覆盖车道与停车区，借墙地反光补足人物面部和衣服暗部；近处清楚，远处略柔略暗，但墙角仍可辨，不形成黑洞。混凝土以浅灰为大面积底色，车漆和服装保留各自本色与适度饱和度，肤色自然，不泛青绿。车身呈现柔和、连续的亮面反射，高光不过曝；混凝土保持漫反射，衣料的褶皱、织物质感与深浅层次清晰，深色衣服不糊成黑块。随画面中已有的移动，受光与车身反射应平缓过渡，避免忽明忽暗；整体反差温和而有空间层次，不做阴森冷调、浓重暗角或湿亮地面的戏剧化效果。
