# A07 | 1.1.0

## 原始请求

给单人舞台肖像写视觉方案：暗背景、浓红色照明、皮肤保留明显汗光，目的是热烈且有身体感。不要改为中性肤色或磨皮，不指定族裔。请给构图、光色、材质及两个成图检查点。没有实际照片。

## 实际输出（仅路径脱敏）

视觉提案：用浓红侧光塑造身体起伏，让明显汗光传达舞台上的热度与身体感。

- **构图**：采用 4:5 竖幅，取头顶至腰部，人物占据画面主要空间。身体略侧、脸朝向镜头，保留颈部、双肩及上臂的连续线条；头顶少留空，两侧暗背景收紧观看距离。
- **光色**：主光从前侧上方斜照，使用浓烈红光、偏硬的光质，让额头、颧骨、颈侧和肩部出现清晰亮面，另一侧落入深红阴影。背景保持近黑，控制溢光；人物暗侧只补微弱红光，维持轮廓可读。皮肤保留红色受光，不校回中性肤色。
- **材质**：保留毛孔、皮肤细纹与不均匀汗珠，让细小亮点和局部成片湿润反光并存，避免整张脸呈均匀油亮。服装建议深色哑光无袖面料，以吸光织物衬托皮肤的湿亮质感；不磨皮。

**两个成图检查点：**

1. **缩略看构图与红光层次**：脸、颈肩和身体朝向能否从暗背景中读出？若红色亮部糊成一块，应局部压低曝光或调整入射角，保留浓红与明暗起伏。
2. **放大看汗光与皮肤**：汗珠、湿润反光和皮肤纹理是否同时可见？若亮斑遮住五官细节，只收窄或压低该处反光，保留其他明显汗光。
