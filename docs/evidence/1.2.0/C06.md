# C06

## 原始请求

使用 film-visual：一只旧黄铜钥匙，道具资产设计。只给一条成图指令。

## 实际输出

设计一只旧黄铜钥匙，写实影视道具资产图：全长约8厘米，椭圆镂空匙柄、实心圆柱匙杆，末端单侧扁平匙齿带两个矩形缺口，结构连接清楚、比例可信；黄铜呈暗金本色，凹处少量褐色氧化，握持边缘磨亮，表面细微划痕体现长期使用，无文字或徽记。钥匙自然平放于浅灰哑光台面，从斜上方近距离拍摄，完整呈现轮廓、匙齿形状与金属厚度；横向3:2画幅，匙柄朝左上、匙齿朝右下，主体占画面约四分之三。左上方大面积柔光形成柔和金属反射，右侧轻微补光保留暗部细节，接触阴影清晰自然，全物件清楚合焦；画面只呈现这一只钥匙，无其他道具、标注或水印。
