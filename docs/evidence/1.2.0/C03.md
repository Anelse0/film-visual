# C03

## 原始请求

使用 film-visual：水彩动画项目，设计一件白色薄棉长裙服饰资产。给一条成图指令。

## 实际输出

水彩动画风格的单件服饰资产：一件白色薄棉长裙，浅圆领、短袖、自然腰线，腰部细密抽褶连接及踝的微阔裙摆，无印花与装饰。肩部自然撑起，胸腰保留舒适松量，袖筒与领口有清晰内腔，裙身随重力形成轻柔纵褶，下摆略有不规则起伏；以完全不可见的隐形支撑呈现立体穿着形态。薄棉哑光、轻软，折叠处略厚，单层边缘轻微透光，不呈现纱裙或丝绸光泽。平视正面、居中竖幅，完整展示领口至裙摆，四周留白，纯白无缝背景。左上方中性柔光，以浅灰褶影和右侧柔和暗部区分白裙与白底，保留白色本色。采用透明水彩薄涂、轻微纸纹与柔和晕染，领口、腰缝和关键褶线清楚，其余边缘适度松软，细节简练。画面仅含这件长裙，不出现人体、皮肤、可见人台、衣架、支架及其他配饰，不平铺，不作摄影写实渲染。
