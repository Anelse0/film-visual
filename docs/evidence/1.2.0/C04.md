# C04

## 原始请求

使用 film-visual：灰色训练 T 恤服饰资产，这次明确要俯拍平铺，便于核对裁片形状。只给一条 prompt。

## 实际输出

单件灰色训练 T 恤服饰资产，写实服装平铺摄影：中性中灰色哑光运动针织面料，圆领、短袖、常规直身版型，无图案与标识。衣服正面朝上，完整平铺于纯白平整背景，双袖自然向两侧展开，衣身与袖片轻轻理平、不拉伸，避免折叠和堆褶遮挡裁片轮廓；清楚呈现肩线、袖窿接缝、侧缝、领口及袖口和下摆走线，便于核对可见裁片的形状与衔接。相机位于衣服正上方，垂直 90° 俯拍，成像平面与铺放面平行，无倾斜透视；衣服居中，领口至下摆及两侧袖口完整入画，四周留白。大面积中性柔光均匀照明，轻微侧向光保留缝线和织物纹理，灰色本色准确、边缘清晰。衣料贴近平面，不呈现胸腔撑起或袖筒鼓起的穿着体积；无人体、人台、衣架、支架、其他服饰或装饰物。
