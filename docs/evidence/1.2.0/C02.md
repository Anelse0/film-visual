# C02

## 原始请求

使用 film-visual：整套服饰资产，米色亚麻长袖衬衫和深蓝直筒长裤，衬衫不塞裤腰。给一条成图指令。

## 实际输出

整套服饰资产图：米色亚麻长袖衬衫搭配深蓝直筒长裤，在同一隐形穿着体上连贯展示。衬衫自然撑起肩部，衣身宽松有厚度，长袖垂落、袖口展开至正常长度，亚麻织纹与柔软褶皱清晰；衬衫下摆全部放在裤腰外，自然覆盖腰头，不塞腰、不局部掖入、不打结。长裤从衬衫下方自然衔接，裤腿保持直筒空间与重力垂感。支撑体完全不可见，领口、袖口仅露合理衣料内面。平视正面、居中竖幅，从衣领到裤脚完整入画，四周留白；纯白无缝背景，左前上方中性柔光配合轻柔补光，保留米色与深蓝本色、织物纹理及暗部层次。只呈现这套衬衫与长裤，不出现人体、皮肤、人台、衣架、支架、鞋或其他配件，不平铺、不拆分拼图。
