# C01

## 原始请求

使用 film-visual：服饰 资产 设计 Sharks 全队穿灰色训练 T 恤。

## 实际输出

**Sharks 全队灰色训练 T 恤｜设计提案**

全队统一采用中灰色圆领短袖训练 T 恤：常规肩线、直身微宽松版型，袖长至上臂中段，平直下摆。面料提案为细密、哑光的速干针织，保留柔软垂坠与轻微弹性。不同队员仅调整尺码，款式、灰色本色、面料和领袖结构保持一致。未提供已确认标识，本版不添加队徽、队名文字、号码或品牌。

**资产展示文字指令**

单件灰色训练 T 恤，采用上述设计。肩部自然撑起，胸腰留有适度运动松量，衣身具有前后厚度；袖筒、领口与下摆保留合理内腔，柔软褶皱沿腋下和衣侧自然垂落，不贴出肌肉轮廓。采用完全不可见的隐形支撑，平视正面居中展示，完整保留双袖与下摆，四周留白，画幅贴合上衣轮廓。纯白无缝背景，左前上方中性柔光使灰色衣身呈现柔和明暗渐变，暗侧仍能读清织纹与接缝。仅展示这件上衣，不出现人体、人台、衣架、护肩或下装，不作平铺展示。
