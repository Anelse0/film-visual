# C09

## 原始请求

使用 film-visual：我有一张平铺的衬衫图，想改成立体穿着资产，但要求原外轮廓和所有褶皱的像素位置完全不变。目前没有附图，先判断这些要求能不能一起成立。

## 实际输出

**按真实、合理的立体穿着标准，这些要求不能同时作为硬性条件成立。**目前没有附图，能判断的是要求之间的冲突，不能判断这张衬衫具体需要改动哪些位置。

平铺改为立体穿着，需要肩部撑起、衣身形成前后厚度、袖筒和领口形成空腔。这会改变衣料的受力、遮挡及投影，原有褶皱的位置和外轮廓通常也要随之调整。

如果外轮廓和所有褶皱的位置都严格锁死，只调整明暗，可以尝试增强**立体错觉**，但不能保证得到合理的穿着形态。

最小放宽建议是：**保留款式、配色、图案、标识与剪裁结构，允许为穿着体积必要地调整局部轮廓、褶皱及受光。**如果像素位置绝对不能动，就应将目标改为“平铺图的体积感增强”，而非“转换为立体穿着资产”。
