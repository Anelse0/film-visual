# C05

## 原始请求

使用 film-visual：新设计一位成年服装模特，真人试穿灰色训练 T 恤，保留脸和双手，正面全身。给一条成图指令。

## 实际输出

新设计一位约 28 岁的成年服装模特，短黑发、自然肤色、五官清晰，体态匀称，采用真实服装棚拍摄影风格。真人试穿中灰色圆领短袖训练 T 恤，哑光细密速干针织面料，无标识，肩线合体，胸腰保留适度松量，下摆自然垂落，清楚呈现袖筒空间、缝线及重力形成的柔和褶皱；搭配简洁黑色训练长裤和低调运动鞋。人物正面站立、直视镜头，双臂自然下垂并略离躯干，双手完整露出，手指自然舒展，不遮挡衣身。竖幅 2:3，正面全身居中，从头顶到鞋底完整入画，四周留适量余白，透视自然。浅米白无缝背景，左前方大面积中性柔光，右侧轻柔补光，以细微明暗呈现灰色衣料体积，保留真实皮肤纹理和面料本色，脚下有轻微接触阴影。脸部与双手清晰可辨，不裁头、不裁手脚，不使用隐形人台，不添加道具、文字或水印。
