# 视频视觉：基调、授权修订与技术测试

## 直接交付基调

场景说明和视觉目标足以写基调，不需要正式分镜或其他 Skill。明确媒介/纹理、时间与曝光目标、空间内光源、人物受光与背景层次、材质、高光/反射、随移动发生的受光变化。把未知灯位写成布光提案；没有人物参考时描述肤色表现目标，不声称核对了原生肤色。

只有场所名称、没有实际空间资料时，使用“【画面基调｜布光提案】”或在段内写“建议以……”来区分拟定照明与已知灯位。直接填好方案，不为缺少灯具资料阻塞交付；不要把拟定灯具称为原有或已锁定。

【画面基调】是可读标题，不是接口字段或权重开关。沿用原文的 LOOK、视觉风格或自然段亦可。不要给所有场景同一套冷灰、无颗粒或低调灯光。文本中的“保持”是目标，不是稳定性保证。

## 信息放置

| 内容 | 对应原文位置 |
| --- | --- |
| 实际参考是谁、保留布局还是沿用光色 | 素材/绑定说明 |
| 汗量、湿衣、道具开关、时段天气 | 状态说明 |
| 共享曝光、肤色呈现、材质与纹理 | 基调/LOOK |
| 某一镜才开的手电、闪光、屏幕 | 原有对应镜头中的局部照明 |
| 台词、时长、镜序、动作、运镜、声音 | 保留原文，除非另有明确授权 |

跨空间的共享基调只写共性。用空间中的窗墙或灯组定位，不固定“画面左侧永远亮”。手电只影响实际打开时的照明；不把停车层灯光铺到影棚或日景。若镜头区域未获授权，只在允许的基调内用场次对应描述；段外冲突另行指出，不因此改镜头句子。

## 只改已有 prompt 的视觉段

1. 读取完整原文和当前授权。语义判断目标区间；不要求换成私有格式。若 LOOK/基调有多个且无法确定，先给适用位置明确的替换段或只问具体修改哪一处，不擅选全文。
   两个独立段落如 LOOK A、LOOK B 同时存在，而用户只说“改 LOOK”且没有说明“全部”，不能把这种含糊指代当作同时修改两段的授权。先明确 A、B 或两处，原文暂不改。
2. 保留原编码、标题、换行、空格与段外文字。默认标题也保留；授权多个区间时逐一定位，不自动包含绑定段或镜头内光线。
3. 生成本场具体视觉文本。参考只保留结构而重新照明时，检查段外是否锁定旧光色。原文的台词、时间、动作、声音不优化、不润色。
4. 将新文本替换到授权区间，而非全文重写或末尾叠加。逐字/逐字节核对所有段外内容。用户要完整稿就返回完整原文加替换结果；用户只要段落就只给段落。
5. 段外冲突逐条引用具体句子，说明仍被保留及所需授权，说明全文仍有冲突。不得宣称已经无冲突可直接提交。

文件修改先读最新版本并留恢复副本。可选 [replace_visual.py](../scripts/replace_visual.py) 只负责确定性拼接和检查，不判断授权和语义，不自动找标题。标准库，无外部模板。

### 字节替换工具

运行前由 Agent 基于真实授权确定起止字节（start 含，end 不含），逐项记录其原片段和新片段的十六进制。用完整输入的 SHA-256 防止修改期间文件变化。工具保留区间外的原始字节；不猜编码，不规范换行，支持多个不重叠区间。

一次性补丁文件格式（仅辅助本次编辑，不是项目数据格式）：

```json
{"sha256":"输入文件的完整SHA256","edits":[{"start":0,"end":6,"old_hex":"414243444546","new_hex":"5859"}]}
```

示例中的字节只是格式演示。实际字符转字节应按源文件编码操作；UTF-8 中文的字符索引不等于字节偏移。混合换行同样保留。先检查：

```sh
python3 scripts/replace_visual.py --input prompt.txt --patch patch.json --check
```

获文件写入授权后输出到不存在的新文件（保留原件）：

```sh
python3 scripts/replace_visual.py --input prompt.txt --patch patch.json --output prompt-revised.txt
```

工具拒绝已有输出、哈希过期、空/重叠/越界区间、原字节不一致和符号链接输出。输出回报 SHA 和未授权字节检查；不把回报称为视觉通过。要替换正稿时先保留原件再用宿主工具执行，并再次核对当前文件未变；无法保真则交文本并说明。

## 用户明确要求的动态视觉测试

自行写一个简单测试：已给动作或中性转头/小幅位移/局部光源变化，固定需要观察的光源与焦点，检查开始、中间、结束和最易失真处。没有已有动作时技术动作标为测试设计，不加入正式剧情，不新编对白或完整正式分镜。

没有实际素材绑定就使用文字视觉目标，不写“图1已绑定”。时长、画幅按当前入口实际支持设置；可以给可选设计时长但不声称官方限制。只写测试 prompt 不等于生成或测试通过；初版不自动执行。
