# 服饰资产：设计、展示与审阅

用于单件服装、成套服装及穿戴配件的独立资产。默认交付一套首选设计和必要成图指令；只要一条 prompt 时直接给完整成稿。服饰内容与展示方式分别决定，避免用“无人”把有穿着体积的衣服变成平铺商品图。

## 先锁定资产与参考职责

1. **范围与款式**：确认本次是一件、一套还是已有服饰的修改。只做已要求的部件；单件上衣完整显示至下摆，不自动加裤子、腰带或鞋。整套按实际穿着关系组合，部件之间有穿插、遮挡和合理衔接，不拆成平铺清单。未提供的剪裁、面料与搭配可以作为提案，不能称已确认。
2. **统一与变化**：团队共用同一款式、本色、面料、领袖结构及已确认标识。尺码可以适配体型，不因此换款或按角色另配颜色。真实穿着状态、汗渍与污损只在任务要求时加入。
3. **参考职责**：实际看图后，区分“照这件衣服设计”和“按这种方式展示”。款式参考锁定用户要保留的版型、配色、图案、标识和层次；展示参考只提供取景、体积、背景、光与材质可读性。不能从展示参考挪用球队、号码、品牌、护具或下装，也不能把已经要求保留的标识一律删掉。兼有两种职责时分别写清保留项。

仅凭文字也可完成新设计；不用等参考图才能采用以下展示标准。只有编辑或核对特定原图必须先取得并查看该图。

## 统一默认：隐形人台式立体穿着展示

独立服饰资产默认采用正面、白底、隐形支撑的立体穿着形态。这里的“隐形人台”指衣服保持穿在合适体型上时的空间关系，支撑体本身完全不可见；不是画一个无头但有皮肤的模特，也不是画一具白色塑料人台。

- **形体与重力**：肩部自然撑起，衣身有前后厚度，胸腰处按版型留出松量，袖筒、领口和下摆有内部空间。褶皱来自接缝、重力与合理受力；柔软面料自然下垂，硬挺面料保留结构。合身不等于贴出肌肉或胸部雕塑。运动 T 恤不继承比赛护肩，裙装不套用球衣肩胸体积。
- **取景与范围**：平视正面、居中，透视不过分夸张，左右结构易比较；完整保留请求资产及四周余量。单件围绕该单件取景；整套按穿着比例连贯展示。画幅由衣服轮廓决定，长裙或整套可用竖幅，宽短上衣无需套用固定 2:3。多角度、细节图与三视图只在要求时增加。
- **背景与光**：纯净白色无缝背景，中性柔光带适度方向性，用渐变和局部暗部读出体积、缝线与织物；保留服装本色。白衣靠轻微明暗和边缘区分白底，不漂白成无轮廓白块；深衣不压成黑洞。不要为均匀照明抹平厚度，也不让高光把针织面料变成塑料。
- **可见内容**：只呈现请求的服饰；领口、袖口等开口可见合理的衣料内面，人体、皮肤、头部、肢体、人台、衣架和支架不入画。不在桌面摊开，也不画悬浮的断肢。帽、鞋等配件保留自身佩戴形态和内腔，不为它们补出整个人体或全套服装。

以上是资产展示默认，不覆盖当前明确要求。用户指定平铺、真人试穿、背面、特定背景或其他方式时执行该要求；不反复询问默认已决定的展示选项。已确定的动画、绘本等媒介继续保留，立体穿着关系不等于必须改成写实照片。剧情人物入景不去掉人物。

## 将设计编译为成图或编辑指令

内部依次组织：**资产范围与款式 → 剪裁/面料/本色/标识 → 穿着体积与部件关系 → 视角/边界/背景 → 光与材质 → 当前必要排除项**。每一项都填成可见结果，不输出空模板或可互换的展示方式菜单。

先说衣服如何被撑起与垂落，再说明支撑不可见；只写“单件、无人、白底”不足以控制展示。排除项针对实际风险，不代替正向描述。没有确认的队徽或文字就不凭队名设计它们；已有标识按本次保留要求处理，不默认新增或清除。

单件指“一件服装的范围”，不指平铺。整套指“同一套衣服在同一隐形穿着体上的组合”，不指同页拼图。仅为统一展示而编辑已有资产时，保留衣服设计，允许为建立穿着体积改变褶皱、轮廓投影和受光；不要同时承诺平铺原图的像素、褶皱和外轮廓完全不变。遇到这些锁定冲突时指出需要放宽的最小项。

默认成稿可直接用于后续生成，但写出成稿不等于已生成或展示标准已通过。模型入口与参数按 [image-prompts](image-prompts.md) 处理；不为这项任务上传参考或执行生成。

## 服饰资产检查

有实际结果图才作成图判断；仅有 prompt 时检查指令是否自洽，记录生成待测。依本次明确展示方式检查：

| 检查对象 | 默认立体资产应看到什么 | 常见偏差及修订方向 |
| --- | --- | --- |
| 资产范围与统一 | 请求的单件/整套完整，同款队服的结构与本色一致 | 多出下装、鞋或队标时移除未授权部件；缺件、裁断下摆则恢复范围 |
| 穿着体积 | 肩、衣身、袖筒、开口有厚度与松量；褶皱适合该面料 | 摊成二维、衣架挂形、硬壳或夸张肌肉形：重建相应局部支撑、空腔或垂坠，不改变款式 |
| 支撑与穿着关系 | 支撑不可见；整套层次、腰口和遮挡连贯 | 露出皮肤/人台、上下装断开漂浮：去除支撑痕迹或修复衔接，保留衣服 |
| 参考与材料 | 只迁移指定职责；原有确认标识可辨；纹理和本色可读 | 展示参考的号码/配色被抄入、针织变塑料、白边丢失：修正相应属性，不全局重设计 |

明确平铺或真人试穿任务以其要求验收，不按默认立体展示判失败。通用的观察、局部修订与前后比较方法见 [visual-review](visual-review.md)。
