# 图像提示词与参考编辑

## 共用方法

选实际目标：新设计、已有图编辑、人物/服饰/道具资产、人物入景。不要为了覆盖模型而为每项任务生成多份指令。最终 prompt 填完已知内容，删去不相关字段。构图、材料、光源与可见结果优先，排除项只针对本次风险。

需要自主作出审美选择时，使用 [design-methods](design-methods.md) 的相关小节。将选定的观看位置、空间关系、明暗/颜色角色、边缘和材质写入成稿；不要混入未选备选或只靠姓名标签。换比例必须说明如何保留必要信息，不能仅改 `--ar` 就声称构图已经适配。仅一条 prompt 的请求不额外展示研究过程。

实际看图后才给特定图片编辑或审阅结论。把每张参考分配到身份、服饰、空间、光色、构图之一或数项；保留与修改不得同时指向同一属性。自然语言中的文件名、图号或“首帧”不是上传动作；尚未上传就称本地参考，不写“已绑定”。

## Midjourney 场景成稿

输出一条英文 prompt：先写具体场所和用途，再写关键空间关系、时段、材料、照明与画面重心，最后写必要构图和已核对参数。未指定媒介时可以采用与任务相符的提案，不默认真人校园剧。无人或有人取决于目标，不固定 unoccupied。

自然语言结构供内部组织，不原样交空模板：

`[specific place and its function], [time / state]. [spatial organization and key materials]. [visible lighting source, exposure and hierarchy]. [framing and intended medium]. [verified parameters]`

只给 16:9 的任务可使用 `--ar 16:9`；用户没有指定版本时无需添加版本标签。用户确实指定 V8.2 且入口支持时可加 `--v 8.2`。Raw、Stylize 等不是电影感保证，不固定附加数值或负面词。新输入版本或参数应先核对当前官方页；离线时省去不能确认的标记，仍交付视觉文本。

Image Prompt 用来影响内容、构图与颜色；文字应描述最终要出现的画面。Style Reference 用来传递媒介、色彩、质感等风格，不是人物身份锁定。网页使用实际参考入口；命令式 `--sref` 仅搭配用户已提供并可用的真实图片 URL，不为生成 URL 自动上传。本地路径不能直接充当平台 URL。V8.2 的编辑路线与旧身份参考参数不同，勿混入旧版 `--cref` 或 `--oref` 当作通用方案。

## GPT Image 编辑指令

按任务用中文或用户指定语言，写清：编辑哪张实际原图、必须保留的属性、唯一允许改变的内容、目标构图/尺寸关系。沿用布局并重新照明时明确只保留几何与指定材质，不沿用旧光色。换画幅或景别属于重构构图，不同时声称像素构图完全不变。

针对原图的最终编辑指令应完整描述结果，不只说“更高级”或“修一下”。指定区域之外保持原样是一项生成要求，仍需后续检查，不能承诺生成一定无损。参考编辑、身份保持能力都不是输出通过证明。

### 人物身份

已有合格资产直接复用；只在需要时补中性身份图。保持当前人物参考中的五官比例、年龄感、体型、发型与可见肤色特征，不引入别的人的脸。中性图以清楚可辨为目标，使用中性背景与均衡、略有方向的光；不继承剧情夜景染色、湿衣或污迹。媒介仍随项目，动画身份图不被改成照片。

未提供身份参考而要求编辑已批准人物图：请求该图，不猜身份；文字新建人物设计可作为新提案继续。

### 服饰和道具

说明是新设计还是保留已有款式；指出剪裁、比例、材料、本色、标识、层次和单一展示角度。服饰可按需求用不可见人台、实穿或平铺；不把某种展示方式强制给所有任务。道具不擅加磨损、发光机构或文字。单套或单件独立成图；三视图仅在用户需要时安排。

### 人物入景与局部皮肤修正

人物入景分别说明空间、身份、服饰职责；构图与已有动作来自本任务。明确照明如何从场景到脸部、如何区分人物与背景。没有带人合格图时这仍是新测试，不称已批准光色母版。

局部皮肤编辑保留原来五官、表情、肤色特征与必要状态，仅处理授权的异常色偏、反光或污迹。不能以“更干净”删除原有雀斑、痣或将人物美白；不能把局部修肤色偷换成全场换光。
