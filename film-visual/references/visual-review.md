# 看图审美审阅与修订

只针对已实际打开的图片作观察。只有提示词时可评审设计逻辑，不能报告成图缺陷；缺目标图时先取得该图。以下检查按任务取用，不输出一张人人相同的评分表。

审阅独立服饰资产时，同时使用 [服饰资产检查](clothing-assets.md#服饰资产检查)，检查衣服的穿着体积、范围与参考保留；剧情人物穿衣画面仍以该场景目标审阅。

## 先判断目标，再判断问题

从当前用户要求和已批准参考确定应保留的特色。粗颗粒、偏低人物、强烈彩光、低反差、油亮皮肤或不平衡构图都可能有意。目标未知时可给条件判断：“如果要突出这位人物，右上招牌会形成竞争”；别把偏好写成客观错误。案例反例见 [style-cases](style-cases.md)。

依次看会改变结论的层次：

- **整体与构图**：实际注意点、人物/物件关系、占比、留白、边界。场所是否还像用户所要的场所？
- **色彩与明暗**：大块关系、相邻轮廓、局部竞争；彩色和黑白各自成立吗？不要求每张图高反差或单中心。
- **光与材质**：人物与背景如何受光，亮点是材料表达还是遮住信息？哪些来源可见，哪些只是推测？
- **风格一致性**：边缘、细节密度、笔触/颗粒是否有明确分工；用户要的粗粝是否被错误“修干净”？

观察写“位置 + 可见现象”，判断解释它怎样影响当前目标；原因用可能性表达，不从像素反推出确定的隐藏灯位、生成参数或物体本色。没有人物不评肤色，没有视频不评动态稳定性。没有执行工具测量，不报精确色值、亮度比或面积百分比。

## 修订必须能对应到观察

优先提出少数影响大的修改。每项说明修哪里、改变什么、保留什么、修后检查什么；必要时提醒会牺牲的特点。别同时改全场配色、镜头、材质和人物位置，导致无法判断哪项有效。

例如，目标是让读者先看人物，实际右上灯箱的白块和密集文字更抢眼：可先降低该灯箱局部反差或简化文字密度，保留人物位置、整体夜色和其他灯具；再看人物是否先被读到，灯箱是否还可辨。若人物不突出是它与背景同明度造成，局部灯箱修复可能不够，应分别指出，不称一次必成。

意图允许空墙和低位人物时，不用居中、裁切和填满背景来统一“优化”。无明显问题时可以说明成立之处和一个待确认点，不为凑数制造缺陷。

用户只要审阅就到此为止。需要编辑指令时转 [image-prompts](image-prompts.md)，把批准的修订写为明确目标；看原图不等于获得编辑、上传或保存授权。

## 比较方案或修订前后

使用同一任务目标和保留项比较，指出每个方向在注意力、空间关系、媒介表达等方面的得失，再推荐一个。两份只有换色的 prompt 不能冒充两个不同构图方向。仅有文字时比较的是方案逻辑；有实际图再比较画面。

存在新旧实际图时，在相同观看条件下检查预定问题是否改善、保留项是否受损、有无新问题。只有原图时记录建议；只有修改指令时记录待执行；输出新图后仍须看图。不要把“修订完成”“关键词齐全”或自评分数写成审美提升证据。
