# 审美设计：把意图变成画面选择

按当前问题读取相应小节：风格与整体视觉、构图、画幅、色彩、光线。下面是设计方法，不是审美定律；可以为用户明确要求的拥挤、冲突、平面化或失衡服务。依据案例与适用边界见 [style-cases](style-cases.md)。

## 风格与整体视觉

先确定本次最重要的观看体验和必须读到的信息，把抽象词落在少数彼此支持的决定上。例如“亲近”可提案为较近的观看距离、人物与工作物件同框、可触摸的材质；“秩序感”也可用重复形状、稳定边界表达。二者都不是固定配色或固定景别。

把风格拆到会改变画面的属性：

| 属性 | 要作的决定 | 要防止的冲突 |
| --- | --- | --- |
| 形与空间 | 几何/有机、规整/错落；空间是包围人物还是让人物亲近观众 | 只换滤镜，场所、比例和物件关系完全不响应目标 |
| 线与边缘 | 轮廓粗细、硬边/软边/消失边，哪些细节省略 | 水彩背景与人物照片级锐边无意拼贴；有意混合时应说明分工 |
| 材质与细节 | 用反射、笔触、排线或色块表示；何处细、何处简 | 每个角落都同等精细，重点被碎细节淹没 |
| 明暗与颜色 | 大块关系、人物和环境的联系/分离 | 同时要求全场高饱和抢眼和只有一个细微色点突出 |
| 时间表现 | 仅视频需要：边缘、纹理、光随既有动作怎样延续 | 从静帧宣称颗粒、线条或受光在运动中稳定 |

用户提到导演、影片或流派时，落实到具体作品、时期或已给参考中的特征；没有材料可作明确标注的风格提案，不把印象写成主创原话。结合参考时说明每份材料负责什么，解决互相冲突的属性。只有姓名、片名或“电影感”不能充当最终设计内容；用户要求保留姓名标签时可保留并补充画面描述。

需要多个方向时，让区别改变观看体验：可以改变人与空间关系、形状、边缘、明暗组织等，不仅换颜色或形容词。保留同一任务的主体、事实和动作；给出首选及相应代价。用户只要一条成稿时，直接选一条成立的方向，不额外提交案例论文或方案表。

## 构图：决定什么被看见，什么被压低

1. 从本次任务定观看关系：一个视觉中心、两个对象的关系，还是均等的群像/图案。不要默认所有图都必须有一个最亮的人脸。
2. 先用大形组织：主体位置与画面占比、两三个主要明暗块、前后遮挡和空白。再加细节。说明观众站在哪里、看向什么、人物与关键物件如何同框；无需凭空报一个焦段。
3. 检查抢眼来源的叠加：亮度反差、饱和色、硬边、密集细节、孤立位置和脸部都可能吸引注意。目标人物很小且柔和时，角落一块白招牌可能压过它。优先改竞争物的位置、局部对比或细节，避免习惯性把全图变暗。
4. 检查负空间与边界的作用：留白是孤立感、尺度还是单纯空缺？边缘截断是否损失用户要看的手、物件或关系？人物偏低、偏边、遮挡和切头可以是有意设计，不自动搬回三分线。

缩略观看有助于判断大形与注意力，全尺寸有助于判断边缘、材质和小物件。未实际缩小或查看时，只能将其列为待执行检查，不能宣称做过测量。注意力判断是基于可见画面的判断，不声称眼动实验或固定分数。

## 画幅：内容和观看关系共同决定

已有交付画幅先遵守。未定画幅时，按需要同框的信息提出首选；“宽银幕更电影感”“竖屏只适合单人”均不足以选择。

| 画面需要 | 可考虑的方向 | 具体取舍 |
| --- | --- | --- |
| 横向分开的两人、路线、多个活动区 | 较宽画幅 | 能读横向关系，但人物占比可能缩小；不能仅用空墙填两边 |
| 人像、近距离双人、上下的空间关系 | 较紧凑画幅或竖幅 | 环境信息减少；需要前后层次或上下安排，不一定必须居中 |
| 环境压迫或疏离 | 任何能组织有效留白的画幅 | 写清空白的位置与意义；宽幅、4:3 都不能单独保证情绪 |

重构画幅时先列必留信息，再决定采用裁切、改变观看距离/角度、扩展未见区域，还是获准后重新安排物件。不同办法改变的属性不同：裁切会丢边缘；拉远会缩小主体；换机位会改遮挡；扩展未见区域属于提案；搬动固定家具会改布局。

“换比例”与“物理布局、机位、景别、所有边缘内容、像素构图全不变”通常无法同时成立。指出冲突，给最小放宽选项；未获授权不替用户决定改变锁定结构。加边框可以保留完整原图，但并未获得填满新画幅的新构图。提示词中的比例仍是生成要求，不是输出尺寸实测。

## 色彩：先安排面积和角色，再选色名

区分物体本色、受光颜色与整体影像处理。墙面发青可能来自墙漆、彩灯或后期；未掌握来源时不要武断改材质，也不要仅靠全局调色修局部问题。

先确定占大面积的环境色与明暗，再安排主体、配角和必要强调色。用“墙地为大面积、服饰占较小面积、标识局部出现”等关系描述即可；不默认 60/30/10、固定色码或互补色配方。暖与冷、红与蓝的意义取决于作品，不固定成某种情绪。

分别检查：

- **明度关系**：色相不同但明度接近时，重要轮廓是否会融在一起？必要时改变相邻明度、边缘或纹理；不要默认提高全局对比。
- **色相与饱和度**：重点靠鲜色突出，还是靠安静区域在繁杂背景中突出？多个色点能否服务群像或节奏？保留用户要的冲突。
- **受光与身份**：彩光可以影响皮肤，修正的目标是本次表达和身份辨识；不把白、无色偏、无光泽当统一合格线。
- **黑白媒介**：直接设计灰阶分组、材料纹理与边缘。红墙与绿衣之类的色名不能替代成图中的明暗分离。

没有实际图片时，上述均为设计提案与检查目标。不要捏造色值、面积百分比或取样结果。参考图的色板只作用于指定任务，不能成为下一个项目默认。

## 光线：把光源、空间与重点连起来

给光一个能在画面里解释的关系：来自哪里、范围多大、边缘软硬、照向谁、哪一侧较暗、背景如何响应。真实灯位未知则写布光提案；有意非写实照明也可成立，说明它承担的表达即可。

按问题选动作：

| 观察或设计风险 | 可考虑的改变 | 同时检查 |
| --- | --- | --- |
| 全部一样亮，主体与背景混合 | 改局部明暗、受光方向或相邻背景，而非必加轮廓光 | 暗侧是否还保留任务需要的信息 |
| 画面明亮却平，空间没有距离 | 保留亮基调，调整前中后层亮度、局部遮光或材料响应 | 是否仍符合用户的明快目标 |
| 空间简洁但缺少变化 | 根据已有光源/新提案设计投影、反射、渐变 | 是否抢走主体，是否无端增加不存在的窗或水面 |
| 人物有光泽或某处很亮 | 先判断它表达湿润、温度、材质还是确实遮住细节 | 别把有意光泽全部抹平；局部问题局部处理 |
| 皮肤与环境同色难辨 | 调整入射光、邻近背景或局部色彩分工 | 不改变身份特征或自动美白 |

材质和光一起考虑：同一光源下，粗木、皮革、玻璃、金属不应只靠颜色区分。亮度、反射宽窄和边缘可表达触感；禁止承诺自然语言能精确控制真实灯功率、光比或生成器渲染参数。

视频只延伸已有动作涉及的受光：人物经过窗边、转头或既有灯开关时哪些关系变化、哪些保留。不为演示审美擅增动作、镜头、天气事件。真实动态结果另测。

## 交付前的设计检查

只检查会影响这次结果的决定：它是否服务目标、与事实和其他设计相容、能否写成可见结果、成图后如何发现失败。需要说明理由时给关键选择和代价即可。写入最终 prompt 的应是选定画面，别把互斥备选、“可考虑”列表或研究过程混进一条成稿。成图后的判断转用 [visual-review](visual-review.md)。
