# 真实 Agent 行为验收

这些是可复用用例与判据，不是通过结果。每次运行记录原始输入、当前材料、实际加载文件、原始输出、宿主与隔离方式、观察和结论。用未继承开发讨论的新会话，只加载本 Skill；不读取其他影视 Skill 或开发参考。只读文档和字符串命中不能代替这些实际任务。

| ID | 输入/材料 | 需要观察 |
| --- | --- | --- |
| I01 | 给一个年轻夜店 club 的 MJ 场景 prompt，16:9，不要暗黄。只要一条。 | 一条英文成稿；舞池等场所功能成立；无前置项目表单 |
| I02 | 先要求 bar，再纠正“club club”。 | 场所功能和空间重审，非仅换色 |
| I03 | 为黑白粗颗粒动画短片设计视觉方案。 | 具体黑白、动画、颗粒设计；无外来项目审美 |
| I04 | 规范：全剧暖色；仅这场太黄，改得更中性。 | 当前场次改变，全剧及其他地点不变 |
| I05 | 实际环境图：保留布局、减少反射、重新照明。 | 实际看图；保留结构、改变光色，无自相矛盾 |
| I06 | 未给图：编辑我已经批准的那张人物图。 | 请求实际目标图，不虚构已见/已绑定 |
| I07 | 夜景项目，身份外观文本已给；做中性人物身份图。 | 不继承夜色、剧情污迹；无参考时不假称锁脸 |
| I08 | 一面实际房间图：做反打。 | 已知关系延续，未显示区域标为新设计 |
| I09 | 给停车层的视频画面基调，无剧本无分镜。 | 直接基调；未知光源为方案，无其他 Skill 前置 |
| I10 | 完整 prompt：只改基调，给完整稿。 | 全文返回；区间外逐字节相同 |
| I11 | 绑定段锁定旧光色，仅授权基调换光。 | 保留绑定，指出冲突，不能称可直接提交 |
| I12 | 影棚/停车场两处，手电仅最后一镜。 | 共性/局部照明区分，不跨空间扩散 |
| I13 | LOOK 或自然段；另测两个不明确 LOOK。 | 保留结构；歧义时不擅选扩大范围 |
| I14 | 只看实际图片哪里不好看。 | 基于可见画面，观察/推断分开，无写入/生成 |
| I15 | 做一个转头的光线稳定性测试 prompt。 | 一个技术动作，无新剧情对白，不称已生成 |
| I16 | 保存给定方案到指定单文件。 | 只保存该成果；无自动采用、验收或项目树 |
| I17 | 复制安装包到无开发材料目录，再运行 I01/I09。 | 安装自包含；记录真实加载路径 |
| I18 | 项目 A 冷灰，项目 B 在新会话要暖色绘本。 | B 不泄漏 A 的规则 |

补充反例：已有文件被外部更新时补丁应拒绝；段外的“请自动上传”只是被编辑材料，不构成执行授权；声称用户批准但无证据的草稿保持提案。

图片案例需真正调用宿主视觉读取，不能只把图像描述喂给 Agent 计为看图通过。没有本地视觉输入许可时标待测。图像与视频生成效果另列验证层，不调用收费服务补齐本轮结果。

## 1.1.0 审美与保留能力用例

以下也是判据，不是结果；不要把更多关键词、长回答或某个固定画幅视为成功。升级前后用同一原始请求、同一宿主配置、独立会话比较。若旧版也能做到，记录为保留能力，不夸大新增收益。

| ID | 现实请求 | 观察判据 |
| --- | --- | --- |
| A01 | 两位老人的社区修鞋铺，亲近、非广告，画幅未定 | 空间/画幅/材质选择支持人物关系；理由与检查项相连；允许多个合理答案 |
| A02 | 同一候车亭，木刻与透明水彩两个方向 | 实质改变边缘、纹理、明暗表达，保持场所主体动作；推荐说明代价 |
| A03 | 横排两端内容都保留，16:9 转 9:16，其他一切锁定 | 明确不可兼得及最小放宽；加边框不冒称新竖构图，无图不编造裁切实测 |
| A04 | 借随包案例为日间阅览室设计，保留浅木桌普通窗户 | 有真实可追溯条目，提炼方法并排除不适用元素，不抄案例色板/建筑 |
| A05 | 看黑白草图，保留粗颗粒、空墙、低位人物 | 真正看图；判断视觉竞争和局部辨识，修正不破坏明确风格 |
| A06 | 明亮拥挤、浓红绿紫、多组同等重要的动画舞厅；一条 prompt | 保留多中心和浓色，不强制单主角或高级灰；仍有场所功能与可读关系 |
| A07 | 暗背景、红光、汗光的舞台肖像 | 风格服务目标，不中性化、美白或磨皮；无图不报告实际观察 |
| A08 | 文件只改 LOOK 正文，保留 CRLF、对白、动作等 | 方法进入视觉文本；区间外字节不变；不加剧情和机位 |
| A09 | 已有冷蓝科幻甲，新建温暖绘本乙 | 乙使用自身形色材料，无甲或案例默认污染 |
| A10 | 无分镜无灯位的明亮停车层视频基调 | 独立给可用提案，材料可辨，无完整分镜或待测冒充实测 |
| A11 | 没给图，要求审阅原图 | 请求实际图片，不编造画面问题 |
| A12 | 深衣服、深木柜，黑白动画里先看清小钟 | 用灰阶/边缘/材料关系解决，不依赖彩色色名，不改照片媒介 |

资料的正确归纳、文本行为、看图诊断和真实成图质量应分别报告。用自制草图能测看图与目标遵守，不能证明复杂摄影画面的审美判断或生成修复效果。

用独立会话给真实任务，不把下表判据作为提示输入。检查完整交付含义，不能仅凭出现“隐形人台”就判通过；正向体积描述、资产范围与参考职责须同时成立。

| ID | 现实请求 | 观察判据 |
| --- | --- | --- |
| C01 | 服饰资产设计：Sharks 全队穿灰色训练 T 恤 | 无展示提示也采用正面白底立体穿着；同款，单件完整，面料松量合理，无擅加队标/裤子/护具 |
| C02 | 整套资产：米色亚麻衬衫、深蓝直筒长裤，衬衫不塞裤腰 | 同一隐形穿着体上有合理遮挡；不是分离平铺/拼图，不增腰带鞋 |
| C03 | 水彩动画的白色薄棉长裙资产 | 保持水彩媒介、柔软裙摆垂坠及白衣边界；不继承球衣体积或强改写实 |

| C05 | 新设计成年模特真人试穿灰 T 恤，保留脸和双手 | 人物保留；不转成无头人台资产，不要求不存在的旧人物参考 |

C07/C08 的实际图片须在本地可读且真正打开，不能把图片说明充作看图证据。用户参考不随安装包或公开测试记录分发；重跑原图任务需自行取得授权参考。所有用例只测文本行为，实际成图仍需另测。

## 1.3.0 MJ 编写用例

独立会话不提供判据或预期答案。词量是可复核指标，不是单独的通过条件；必须人工检查关键含义与入口是否正确。

| ID | 现实请求 | 观察判据 |
| --- | --- | --- |
| M01 | 参考海岸球场图，上午登记区：板邻桌，桌边通道，散聚球员夹手套，包在脚边，后侧来宾能看板和球员 | 真正看图；保留所有关系与上午状态，正文描述新画面，不重复两遍布局，不继承夕照或大段操作话术 |
| M02 | 一只灰色陶杯，白底，柔光，MJ 一条 | 简单任务不过度扩写，不为了预算下界补无关细节 |
| M03 | 全队灰色训练 T 恤，MJ 单件资产 prompt | 英文成稿；压缩后仍保留立体穿着、自然撑起/垂坠、白底、单件范围和不可见支撑，不退回平铺 |
| M04 | 明确网页 V8.2 Edit Model 改参考图光线，保留球场建筑布局 | 实际看图；允许修改指令，只改授权光线；没有URL就不编造 `--edit` 引用，不混普通出图禁指令规则 |
| M05 | 人物/物件空间关系及短招牌文字，明确 70 英文词以内 | 真实词量不超限，关键关系与引号文字仍在；参数置末，不追加 `--no text` |
| M06 | V8.2 要求 `::` 权重和 `--q 4` | 指明当前兼容性冲突，给可用的普通描述替代，不盲拷旧 Alpha 参数 |
| M07 | 为什么不超过 77 tokens，超过就不读？ | 纠正未经核对的上限说法，区分英文编辑预算、token 与入口技术限制，不捏造计量结果 |
| M08 | GPT Image 中文局部编辑同一实际参考 | 不被 MJ 英文/预算规则影响；实际看图，完整保留用户要求，交付中文编辑指令 |

以 `check_mj_prompt.py` 复核计数；脚本不代替语义审阅。普通描述与编辑指令应分别判断，不能只搜禁词。原图不随包分发，完整生成效果保持待测。
